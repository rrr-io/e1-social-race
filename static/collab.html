Counts valid ENHYPEN voting proofs sent by partner fandoms. A proof is valid when the last image of the Mnet Plus certificate is ENHYPEN and its certificate ID has not been counted before. Anything that cannot be verified with certainty waits in the manual review queue.

1. ENHYPEN reference

Upload one or more correct certificates (ENHYPEN as the last image). Their last image is the comparison target. If that photo changes between categories or rounds, add one reference for each version.

2. Collabs

Each partner fandom sends its own kind of certificate. Define the collab and where its own image sits on the certificate (for example the first image); ENHYPEN must always be the last. Then add a sample certificate for that collab as its reference. A collab without a partner image is checked for ENHYPEN only.

3. Upload proofs

Choose a folder (best for thousands of files) or individual screenshots. Files already processed are skipped, so after an interruption you can select the same folder again and continue.
